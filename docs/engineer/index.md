# ⚙️ SnowPro Advanced: Data Engineer (DEA-C02) — Vue d'ensemble

## Format de l'examen

| Élément | Valeur |
|---|---|
| Code | **DEA-C02** (remplace DEA-C01 depuis le 18/02/2025) |
| Questions | **65** (choix multiple, sélection multiple, interactif) |
| Durée | **115 minutes** |
| Score requis | **750 / 1000** |
| Prix | 375 $ (300 $ en Inde) |
| Validité | 2 ans |

## Prérequis officiels

!!! danger "Prérequis bloquant"
    - **SnowPro Core (COF-C03) certifié et valide** : **obligatoire** pour s'inscrire.
    - **Recommandé** : **2 ans** d'expérience en data engineering de production, dont de la pratique Snowflake.

!!! info "Profil visé"
    Ingénieur capable de concevoir et d'optimiser des pipelines de bout en bout : ingestion, transformation, réplication inter-cloud, streaming quasi temps réel, tuning de performance et évaluation de métriques.

## Domaines & poids officiels

| # | Domaine | Poids | Priorité |
|---|---|---|---|
| 1.0 | Data Movement | **28%** | 🔴 Critique |
| 5.0 | Data Transformation | **25%** | 🔴 Critique |
| 2.0 | Performance Optimization | 19% | 🟠 Important |
| 3.0 | Storage & Data Protection | 14% | 🟡 Utile |
| 4.0 | Data Governance | 14% | 🟡 Utile |

!!! tip "Stratégie"
    Data Movement + Data Transformation = **53%** de l'examen. Ce sont les deux domaines à verrouiller en premier. L'examen est très **scénarisé** (choisir la meilleure solution, pas réciter une syntaxe).

## Nouveautés DEA-C02 vs DEA-C01

- Domaine 4 renommé **Data Governance** (au lieu de « Security »).
- Ajout explicite : **Dynamic Tables**, **Iceberg external tables**, ingestion de données **non structurées**, **Horizon Catalog**, **Snowflake dbt Projects**, **Cortex** (catégorisation, multimodal, text analytics), **Snowpipe Streaming** vs Kafka connector.
