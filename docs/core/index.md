# 🎯 SnowPro Core (COF-C03) — Vue d'ensemble

## Format de l'examen

| Élément | Valeur |
|---|---|
| Code | **COF-C03** (remplace COF-C02 depuis le 16/02/2026) |
| Questions | **100** (choix multiple, sélection multiple, interactif) |
| Durée | **115 minutes** |
| Score requis | **750 / 1000** (scoring mis à l'échelle) |
| Prix | 175 $ |
| Langues | EN, JP, KR, et FR / ES (depuis avril 2026) |
| Validité | 2 ans |

## Prérequis officiels

!!! info "Prérequis"
    - **Aucun prérequis formel** : tout le monde peut s'inscrire.
    - **Recommandé** : au moins **6 mois d'expérience pratique** de la plateforme Snowflake.
    - **Connaissances supposées** : ANSI SQL de base, fondamentaux du cloud computing.

!!! tip "C'est le socle"
    Réussir le COF-C03 est **obligatoire** avant de pouvoir passer le DEA-C02 ou le SPS-C01.

## Nouveautés COF-C03 vs COF-C02

- Accent plus fort sur l'**IA** : Snowflake **Cortex** (AI SQL functions, Cortex Search, Cortex Analyst), **Snowflake ML**.
- **Notebooks**, **Streamlit in Snowflake**, **Snowpark** dans le domaine Architecture.
- Tables **Apache Iceberg** et **Dynamic Tables** listées explicitement.
- **Git integration**, **Openflow** (non testé tant que pas GA mondial).
