# 🎯 SnowPro Core COF-C03 — Vue d'ensemble

## Format de l'examen

| Élément | Détail |
|---|---|
| Code | COF-C03 |
| Questions | ~100 QCM |
| Durée | 115 minutes |
| Score requis | 750 / 1000 |
| Coût | **$175** |
| Validité | 2 ans |
| Renouvellement | Programme CE (formation ILT ou certification supérieure) |

!!! info "Nouveau depuis février 2026"
    COF-C03 remplace COF-C02 (actif depuis le 16 février 2026). Focus plus important sur les outils **AI** par rapport à l'ancienne version.

---

## Prérequis officiels

- **6 mois minimum** d'expérience pratique avec Snowflake
- Familiarité avec **ANSI SQL de base**
- Connaissance des **fondamentaux cloud** (types de services, architecture stockage/calcul)
- Connaissance des **bases de données** (tables, vues, procédures stockées, sécurité)

!!! warning "L'examen ne teste PAS les fondamentaux SQL ni cloud directement"
    Mais certaines questions supposent que tu les maîtrises.
